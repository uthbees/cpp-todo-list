## C++ todo list

This is a simple but polished todo list terminal app written in C++. It has a lot of work put into the command manager,
including an undo/redo system.

I made it for the final project of a C++ class in about 8 hours. I focused on making both the UX and the code as high
quality as I could, so it feels good to use and is as maintainable as possible.

You can build and run it with cmake:

```bash
cmake --build .
./cpp-todo-list
```
